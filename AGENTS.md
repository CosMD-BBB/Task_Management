# User design preferences

These are user requirements for this CosMD team workspace. Preserve them during later layout, feature, data, filter, color, and theme changes unless the user explicitly changes them.

- Use **Manrope** for English and numerals and **Sukhumvit Thai** for Thai. The supplied Thai font's internal family is **Sukhumvit Set**. The user confirmed this pair on 6 October 2026 and reaffirmed it on 9 October 2026. Do not replace it with a template font or rename another font to match this family. Bundle authentic font assets and verify actual rendered font use on desktop and mobile.
- Apply the same font pair to headings, body, navigation, forms, task fields, buttons, and all three task views. Keep it unchanged when switching light and dark mode.
- Use recognizable channel colors: Facebook blue; Instagram purple/pink with orange; TikTok black with cyan/pink; YouTube red; LINE green. Keep colors consistent between option cards, selected chips, and task views.
- Content types must have vivid, visibly different colors. Preserve each label's color across selection and task views; custom labels also need stable colors.
- Keep names/icons and visible selection checks alongside color. Text must remain readable in both themes.
- Task content types, posting channels, and assignees support multiple choices. Keep these choices immediately available from task fields, with a clear save action.
- Tasks have a persistent discussion for comments, captions, and revision requests. Preserve multiline text, authors, timestamps, and @mentions of project members, with in-app notifications that open the mentioned comment. Keep Viewer access read-only and render messages as safe plain text.
