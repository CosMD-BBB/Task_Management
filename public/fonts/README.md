# CosMD brand fonts

## Manrope

`Manrope-Variable.ttf` is the authentic variable font from the official
Google Fonts repository. It supports upright weights 200–800.

- Source: https://github.com/google/fonts/blob/2eb0b48d5f760f62e286216f0859a8c540dbc1bd/ofl/manrope/Manrope%5Bwght%5D.ttf
- Upstream revision: `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`
- SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`
- Size: 164,700 bytes
- License: SIL Open Font License 1.1; included as `Manrope-OFL.txt`.

The font is served locally, so displaying English and numbers does not
require a request to a third-party font service.

## Sukhumvit Thai / Sukhumvit Set

CosMD's required Thai font is **Sukhumvit Thai** (internal family name
**Sukhumvit Set**). Its actual licensed brand assets are not present in
this cloud checkout. The prior user-supplied assets exist on the user's
Mac, outside the files accessible to this cloud environment.

The requested files are `SukhumvitThai-300.ttf`, `SukhumvitThai-400.ttf`,
`SukhumvitThai-500.ttf`, `SukhumvitThai-600.ttf`, and `SukhumvitThai-700.ttf`.
Use those real files or an authorized source for them. Do not rename a
different font or register it under the Sukhumvit family name.

Until those assets are supplied, an installed Sukhumvit family can be
used on compatible devices; a system fallback is still necessary elsewhere.
This is an incomplete Thai-brand-font integration, not a bundled Sukhumvit font.
